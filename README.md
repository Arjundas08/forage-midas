# J.P. Morgan Software Engineering Virtual Experience

This project was completed as part of the **J.P. Morgan Software Engineering Job Simulation** on **Forage**.

## 🚀 Overview
I implemented a backend system using **Spring Boot**, integrating real-world tools used in financial applications.

## 🧩 Modules Completed
- **Project Setup** – Configured dependencies and base structure.
- **Kafka Integration** – Set up a message broker for real-time data streaming.
- **H2 Database Integration** – Used an in-memory database for transactions.
- **REST API Development** – Created and tested endpoints for data access.
- **REST Controller** – Managed API routing and logic.

## 🛠️ Technologies Used
- Java Spring Boot  
- Apache Kafka  
- H2 Database  
- RESTful API  

## 🎯 Key Learning
This simulation strengthened my backend engineering skills and improved my understanding of how distributed systems and event-driven architecture work in financial environments.
